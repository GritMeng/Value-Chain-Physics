# 🔮 IPC 智能计划控制塔图形化操作手册 (GUI Operation Manual)

本手册专为习惯使用图形化界面（GUI）的业务计划员与系统架构师设计。您不需要在命令行（“黑窗口”）中敲击任何代码，即可完成系统启动、数据导入、SQL 查询、策略调整及 C++ 引擎重算。

---

## 🚀 一、 一键启动控制塔界面 (Launch the Cockpit)

我们已在您的电脑桌面创建了快捷方式。

### 1. 启动步骤
1. 回到 Windows 桌面，双击 **`IPC_Cockpit`** 图标。
2. 系统会自动弹出两个窗口：
   - **后台控制台（黑窗口）**：这是运行后台计算服务与服务器的进程，**请将其最小化，切勿关闭**。
   - **浏览器网页界面 (http://127.0.0.1:8501)**：控制塔主视觉看板和协同驾驶舱。
3. 如果浏览器没有自动打开，请手动在浏览器地址栏输入并访问：`http://127.0.0.1:8501`。

---

## 📊 二、 在 DBeaver 中图形化管理数据 (DBeaver Database Guide)

DBeaver 是一个专业的图形化数据库管理工具。您可以像操作 Excel 表格一样在其中直接修改、查询和导入数据。

### 1. 配置 DuckDB 连接
1. 打开桌面的 **DBeaver** 程序。
2. 点击左上角的 **“新连接” (New Connection)** 按钮，在列表中选择 **`DuckDB`** 数据库类型。
3. 在连接属性配置中，找到 **`Database File`** 输入框，点击右侧的 `Browse` 浏览按钮。
4. 选中您的 IPC 工作区主数据库文件：**`H:\IPC\ipc.db`**。
5. 点击 **“完成” (Finish)**。

### 2. 像 Excel 一样查看与编辑数据
1. 在 DBeaver 左侧的数据库导航树中，依次展开：`DuckDB` -> `Schemas` -> `main` -> `Tables`。
2. 双击任意一张表（例如在库库存表 `ipc_onhand`）。
3. 在右侧主窗口中，切换到 **`数据` (Data)** 标签页。
4. 您将看到网格状的所有数据：
   - **过滤/排序**：可以直接在列头上右键进行排序或过滤筛选。
   - **直接修改**：双击任意单元格即可修改数值。修改完成后，点击下方的 **`Save` (保存/Save changes)** 按钮即可将修改写入数据库。

### 3. 图形化导入 CSV 外部数据
1. 在 DBeaver 中，右键点击您要导入数据的目标表（例如 `ipc_onhand`），选择 **`导入数据` (Import Data)**。
2. 在弹出的向导中选择 **`CSV`**，点击下一步。
3. 选择您要导入的本地 `.csv` 文件路径。
4. 在列映射页面，DBeaver 会自动帮您对齐表字段与 CSV 列头，确认无误后点击 **`继续`** 并点击 **`完成` (Start)**。
5. 导入完成，刷新该表即可看到最新数据。

## ⚙️ 三、 图形化触发 C++ 求解内核计算 (Triggering Calculations)

当您在 DBeaver 中调整了输入数据，或者想调整业务指标时，不需要使用命令行，可以直接在浏览器大盘中一键触发计算：

### 1. 操作步骤
1. 打开浏览器控制塔主页面 (`http://127.0.0.1:8501`)。
2. 在左侧侧边栏的“功能工作簿 (Workbook)”中，选择 **`⚙️ 规划参数与策略调整`** 表单。
3. **策略微调**：
   - 可以在页面中直接用鼠标微调 `IBP 销售共识需求 Override` 的预测量。
   - 或者设定特定物料的 `IO 安全库存服务水平 (SL)`（例如从 95% 调高到 98%）。
4. **一键重算**：
   - 调整完参数后，点击下方的 **`⚡ 执行自上而下分解与排产拉动`** 按钮。
   - 此时页面会显示等待动画（Spinner），后台会自动调用 C++ 求解内核（`test_runner_validation.exe`）进行消纳平衡与约束求解，并在计算完成后自动更新 `ipc.db`。
5. **查看结果**：
   - 计算完成后，刷新当前页面或切换至 **`📋 时序物料平衡表 (MRP)`** 工作簿，即可在网页图表中直观地查看最新算出的可用库存趋势以及替代料分配对账明细，完全无需命令行参与。

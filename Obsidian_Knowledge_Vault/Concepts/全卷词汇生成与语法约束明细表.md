# 📜 全卷词汇生成与语法约束明细表（专著立宪·词汇宪法）

> **宪法说明**：本明细表划定了《系统与复杂性科学：秩序的构建、存续与进化》全书一至四卷的**绝对词汇边界与生发语法**。严禁在前面卷次中“预支”后置卷次之词汇；每一个核心概念必须随章节推进，实现由定性哲学到形式算子、再到工程实例与跨域判决的无缝递进。

## 📖 第一卷《秩序》：秩序之元（第一性原理）

* **本卷生成之合法词汇**：
  - **基础实体相态**：混沌、无序、观察者、元认知 ($\mathbf{\Phi}$)、划界 ($\Pi$)、识（一阶认知）、知（二阶元认知）。
  - **实在三分法**：实然 ($M$)、应然 ($\Pi(S)$)、残差 ($\Delta$)。
  - **三大第一性公理**：构建（框架防瓦解）、存续（约束防耗散）、进化（残差防停滞）。
  - **结构特征**：全息、自省、收敛、闭环、相变。
* **严禁预支之词汇**：
  - 相空间、流形、张量、算子、变分自由能、李雅普诺夫指数、双螺旋、SKU、BOM、ROIC。

## ⚡ 第二卷《八大物理宪法》：系统工程的降维投影

* **继承上一卷**：完全继承第一卷的所有词汇，并将其转化为形式化算子。
* **本卷新增生成之合法词汇**：

  - **热力学与控制论**：变分自由能 ($F$)、香农熵、信息负熵、计算耗散熵 ($S_{\text{comp}}$)、非独立同分布 (Non-IIDness)、正交投影、粗粒化、重整化、矢量标量积做功 ($W = \|M\|\|\Pi\|\cos\theta$)、错配夹角 ($\theta$)。
  - **数学极限与死线**：李雅普诺夫指数、哥德尔不完备边界、图灵停机死角、莱斯语义边界、影子价格（拉格朗日乘子 $\lambda$）。

  - 数据模型 ($D$)、业务算法 ($A$)、SKU、BOM、ERP、O2C、S&OP、加权平均资本成本 (WACC)。

## 🔄 核心概念跨卷演化示范：以“残差”为例

为展示“语言无透支”在全书中的递进轨迹，以核心词汇“残差”在四卷中的生成过程为例：

```
第一卷：残差 (Residual / Mismatch)
└─ 定义：应然流形与实然背景在观测接口处的差异（纯概念定性）。

第二卷：全息感知残差向量 Δ(t) 与变分自由能 F
└─ 演化：升维为物理算子，作为触发算符重整化 (Φ) 与哥德尔破壁的做功梯度；
    量化为信息熵与物理熵的差分接口。

第三卷：全息计划偏差与配额缺口 Δ_O2C
└─ 降维：实例化为供应链网格中，ATP/CTP 推演与真实物料齐套/机台产能之间的张量差分；
    成为驱动数字双螺旋 ⟨D, A⟩ 内存高频计算的输入信号。

第四卷：临界宏观偏差 ΣΔ_crit 与判决性观测值
└─ 测度：作为判决传统系统失效与验证全息抗熵引擎代际跃迁的宏观观察量；
    在航天工程、AlphaFold 与 IPS 中兑现为系统纠偏的物理依据。
```
